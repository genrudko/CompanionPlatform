Completed.

Functions:
- summaries;
- decision extraction;
- handoff generation;
- state updates.

## Phase 4 — ChatGPT Bridge

Possible implementations:
- browser extension;
- future integrations.

## Phase 5 — User interfaces

Desktop and Android clients.

## Non-goals

Do not start with:
- AI swarm;
- autonomous developer;
- IDE replacement;
- excessive infrastructure.

## Success criteria

- state survives chat changes;
- decisions are preserved;
- evidence is stored;
- manual handoff is reduced.
