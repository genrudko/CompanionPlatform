# Companion Platform Architecture

## Purpose

Companion Platform provides persistent engineering context between human, AI models and execution environments.

## Core principles

1. LLM is not the source of truth.
2. State belongs to Companion Core.
3. Decisions require evidence.
4. Interfaces are replaceable.
5. Human remains final authority.

## Layers

### Intelligence Layer

Examples:
- ChatGPT Plus;
- OpenRouter;
- local models.

Responsibilities:
- reasoning;
- planning;
- communication.

### Core Layer

Responsibilities:
- state;
- memory;
- projects;
- events;
- decisions;
- orchestration.

### OS Layer

Responsibilities:
- execution;
- files;
- services;
- devices.
